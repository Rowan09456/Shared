# Shared
This repository is intended as a submodule for the the group projects. 
It holds the following components  
- FreeRTOS
- Device Drivers

  
All group projects can contribute to this repository.  
The minimum acceptable criteria for pushing to this repository are:  
- Resolving conflicts
- Not breaking builds

  
The instructor will run an automatic script which verifies the build-ability of this everyday.  
If instances of breaking the rules above are discovered, the individual and group will be penalized.
